# Wellnous

I'd like to make www.wellnous.net (https://wellnous.godaddysites.com) far more modern with strong content but more digestible with cards and more scrolling options. Build it as an educational health and wellness knowledge hub with modular topic cards, horizontal scroll trays, and quick-takeaway chips across Everyday Nutrition, Physical Protocols, and Supplements. Keep the Wellnous Kombucha as a small side part rather than the main focus.
